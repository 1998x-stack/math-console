# 数学图片原生视觉 Golden Benchmark（首批 3 道原创题）

这不是 OCR 数据集，也不通过脚本识别图片。图片只由支持原生视觉的 Agent 在当前多模态会话中直接看；评估结果由数学审校者根据标准答案填写。

## 素材

- `cases/derivative.svg`：函数与导数，含下标、量词、不等式和证明。
- `cases/analytic-geometry.svg`：解析几何，含圆、直线方程和示意图。
- `cases/solid-geometry.svg`：立体几何，含正方体、角的投影和带下标的点名。

均为本仓库原创测试题，不包含学生真实资料。当前 SVG 可直接在浏览器打开；使用 Codex `--image` 前应把 SVG **仅栅格化成 PNG**（浏览器导出或图像格式转换），这一转换不包含 OCR、数学识别或脚本式看图。

## 执行方式

1. 使用用户界面的图片附件或 Codex CLI `--image` 将 PNG 交给具备视觉能力的 Agent。不得只发文件路径字符串，也不得通过 OCR/第三方模型调用程序提取题干。
2. 要求 Agent **先直接复述图中全部题干、公式、子问、图示标记、候选歧义和视觉来源**，再生成 problem.json。
3. 不给解题 Agent 看 `golden.json`；由独立数学审校者在完成后用 golden.json 的答案与陷阱核对。
4. 每题分别记录：识图全部子问覆盖率、符号正确性、额外编造条件次数、数学解答正确性、独立审校真实性、教学关键步骤解释、实际 Agent 委派是否成功。
5. 只在实际原生视觉会话成功执行并保存来源、模型、运行上下文和评分后，才将 review_status 从 pending 标记为完成。

## 当前已实现与未实现

已建立 3 个不同数学主题的原创可见题面及人工可核对的参考答案。**尚未在 Codex/Pi/Claude/OpenCode 的真实视觉模型中进行测试**；本数据集的静态单元测试只验证 fixture 完整性，不等于视觉正确率。

建议下一轮扩展到 30 道题（每类 10 道，逐步增加模糊图形、复杂公式与压轴题），并给每道题采集真实 Agent 输出及人工核对报告。
