# Codex：先看图，再解题（Agent 原生视觉）

请**直接观察我上传的数学题图片**。不要写或运行任何 OCR、Python、Pillow、OpenCV 或图片转文字脚本来理解图像。图片需要实际进入当前 Codex 多模态模型上下文；如果你只有文件路径却不能查看图片，立即声明无法读题，不要编造。

第一步：凭你自己的视觉理解，逐项复述图片中看到的题干、条件、公式、分式、参数范围、图形已标记的点线角以及所有小问。将“图中明确给出”与“你推导出的结果”严格分开。看不清的符号写出候选读法，不猜测。

第二步：由 math-image-interpreter 或实际看过原图的主 Agent 生成 problem.json，随后再根据现有 Schema 做**结构校验**。init、check 等 Python 脚本只管理文件、哈希与格式，不负责识别任何数学内容。

第三步：在 G0 完成后交给 math-solver 写可讲解的 solution.md / solution.json；使用独立上下文 math-proof-auditor 做数学审校（高风险题需要真实教师确认），再继续 storyboard、可编辑 Manim、隔离渲染 MP4 与 PPTX。

如果子 Agent 无法访问原图，不要说它已完成看图。由具有原生视觉能力的主 Agent 观察并明确真实交接；对数学或图片存在未解决的歧义则停在 G0。

这是一个**Agent 理解数学图片**的工作流，不是一个 Python 识别图片的流水线。现在从亲自看图开始。
