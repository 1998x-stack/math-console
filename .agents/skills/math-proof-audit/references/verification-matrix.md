# 数学验证矩阵与证据等级

## 审校不等于重复答案
同一 Agent 在同一上下文看完自身解答后说“校验通过”不算独立审校。由不同 Agent / 隔离上下文、不同求解路线完成；审校 Agent 应优先寻找错误而非强化原答案。

## 证据等级
- L0：语言模型自述“我检查过”——**不可作为通过依据**。
- L1：静态结构一致：字段、步骤 ID、参数范围与小问映射正确。
- L2：符号计算/数值测试/随机采样支持局部计算结论；不覆盖未试参数。
- L3：具有清晰前提、完整逻辑、可复核的数学证明或经独立推导的等价证明。
- L4：真人教师对高风险证明的签核；必须记录真实 reviewer_name、时间和具体修改意见。

## 必查项目
- 领域：定义域、可导区间、分母不为零、对数/根式要求。
- 逻辑：`\Rightarrow` 与 `\Leftrightarrow` 的区别，量词与存在性。
- 参数：阈值、开闭区间、极端值、是否与定义域冲突。
- 极值：驻点不等于极值；单调性必须有符号变化或其他严格依据。
- 几何：平行/垂直/共线/角度来源；图形只能辅助直觉。
- 不等式：等号何时成立，乘除是否要求符号，是否有未证明的正性。
- 概率：样本空间、独立性、条件概率和边界。
- 解题教学：是否使用超出课程标准的高级定理、是否附高中版证明。

## 可审计 audit.json
`verdict=pass|revise|block`，`reviewer`（id、role、independent_from_solver），`independent_method`，`checks` 每项含 passed/evidence/step_ids，`tested_cases` 和 `unresolved`，以及 `human_review`。

高风险证明应当记录 human_review.required=true；工作区默认 auto_waiver 可以在 G2 独立审校通过后免教师签字继续，但记录为 waived_by_default_policy 而非真人签名。strict 模式要求 reviewer_name、reviewed_at 和最终产物签核文件。字段存在本身不能证明真人身份。

## 复核示例
`f(x)=x\ln x-ax` 在 x>0 上导数 `\ln x+1-a`。
独立方法：由 `\ln x` 严格递增，导数零点唯一且符号先负后正；或用 `f''(x)=1/x>0` 证明凸性并结合 `f'` 零点。
反例方向：是否遗漏 x=0（原函数没有定义）；是否误写 `e^{a}`。
