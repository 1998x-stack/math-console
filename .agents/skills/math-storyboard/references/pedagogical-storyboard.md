# 数学教学分镜设计规范

## 每个 beat 的六要素
- **scene_id**：稳定标识；与 Python Scene 的逻辑分段一致。
- **step_ids**：明确来源；没有对应步骤的铺垫镜头可以使用空列表，但全局必须覆盖全部关键步骤。
- **visual**：图形、对象、颜色对比、焦点及动画动作，注明需保持不动的对象。
- **voiceover**：适合口语的中文逐字稿，包含符号的口头读法；不得讲出尚未说明的结论。
- **pedagogy**：为什么在此时展示此画面，学生应观察什么，何处提问。
- **duration_s**：预计时长并与配音进行同步验证，**不是**最终时长事实。

## 教学节奏
1. 15 秒内呈现问题或冲突：为什么要研究导数的符号？
2. 用一张静态关系图建立对象：定义域、函数、坐标系。
3. 变化画面只展示关键变量：如参数 a 滑动时临界点如何移动。
4. 暂停提出可回答问题：“导数由负变正意味着什么？”
5. 按 Step ID 展示严谨推导：函数值或符号表、单调区间、不等式证明。
6. 最后给出方法迁移和易错点，而不是重复最终答案。

## 视觉语法
颜色承担意义：青色表示研究函数、琥珀色强调关键临界点、红色强调待纠正误区。不要只用颜色区分正确/错误，辅以标签。中文 Text 与 TeX MathTex 分开，避免字体缺字。背景与正文字体有足够对比。每屏最多 1~2 个结论，复杂式子分行变换。

## 经典导数分镜示例
- beat 1：展示 f(x)=x ln x-ax 与 x>0，解释“为什么先看定义域”。
- beat 2：导数 f'(x)=ln x+1-a，突出 “ln x 严格递增”。
- beat 3：解 f'=0 得 x0=e^{a-1}，动线突出导数零点的位置。
- beat 4：符号变化表/单调性箭头，强调“先负后正”及唯一极小。
- beat 5：教师暂停提问：“如果 a 很大，临界点还在定义域吗？”（是：e^{a-1}>0。）

## 旁白与字幕
切分短句，给公式留思考停顿；术语首现给予解释；字幕要避免遮挡图像；不要将演示预估时长当作实际视频对齐完成的证据。

## 错误不可视化
任何已被 audit 标为 unresolved 的数学步骤都不能进入分镜；若教学设计引入新定理或数学命题，返回独立审校。
