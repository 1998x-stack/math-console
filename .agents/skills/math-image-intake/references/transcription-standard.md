# 数学图片转录规范

## 录入顺序
1. 可见的学段、年份、题号（仅作为来源信息，不作为数学条件）。
2. 共享题干，保留全部定义域、参数范围、条件与结论。
3. 每小问原文、公式 LaTeX、编号；公式不允许把 “≥” 写成 “>”。
4. 图形：点名、坐标、文字标签、弧度/角度、辅助线、虚线、阴影区域与已知等量关系。
5. 页面外裁剪部分、看不清的字符、手写涂改，进入 ambiguities。

## 误读高风险示例
- 负号与等号：`-a` 不等于 `=a`。
- `\ln x` 不是 `1n x`；`\log_a x` 底数不可省略。
- `x_n` 与 `x^n`；`f'(x)` 与 `f(x)`。
- `\forall`、`\exists`、`\in`、`\notin`。
- 条件 `x>0`、`x\ge 0` 和 `a\in\mathbb R` 是不同问题。

## 多小问原子化
每小问唯一 id；问题之间可共享函数模型和图形，但下游解答、教师提示与动画场景分别挂钩 question_id。绝不把第（3）问“证明某个不等式”自动扩写为未经提供的具体命题。

## 可信度声明
不要给出没有依据的“99.9% OCR 精确率”。只在包含明确辨识证据时记录 confidence；任何未解决歧义会被 G0 阻止。

## 示例
给定 `f(x)=x\ln x-ax`，原题如果只给第（1）（2）问，那么 questions 仅录入两问；第（3）问未知时不得凭空添加。定义域 `x>0` 是后续求解需要检查的数学推导条件，并非题面可以随意增写的已知条件。
