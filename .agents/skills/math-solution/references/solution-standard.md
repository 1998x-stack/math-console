# 高中数学解题质量规范

## 书写目标
学生能看懂，同行教师能逐行复核，可被 storyboard 引用且不会因动画而丢失严谨性。

1. **读题**：写出已知、待证、数学对象及取值范围。
2. **策略**：分析决定性结构而非只展示最终计算。例如含 ln 的函数先审域 x>0，再求导；含周期表达式先考虑周期、对称与渐近结构。
3. **步骤**：每一步有 claim 与 reason；变形要写清是否等价/蕴含，尤其乘除未知符号、平方、换元。
4. **边界**：所有参数分支、取等条件、是否存在极值与唯一性。
5. **验证**：数值/符号检查可附上，但不得把有限抽样当一般性证明。
6. **教学解释**：把“为什么想到这个方法”单独列出，尽量用高中可接受的论证。

## 上海高中教学常见风险
定义域遗漏、求导不等于完成单调性证明、把数值趋势当全称结论、极限与近似没有误差界、空间几何的图像不构成证明。

## 结构化映射
每个 solution.steps[i].id 必须唯一，question_id 来自 problem.questions；depends_on 只能引用已有步骤 id。results 对每个小问恰好一个结论；复杂小问可用多个步骤。Markdown 标题使用小问编号、步骤 ID、结论、易错点和可视化机会。

## 示范
`f(x)=x\ln x-ax`（x>0）：
`f'(x)=\ln x+1-a`，临界点 `x_0=e^{a-1}`。
当 `0<x<x_0` 时 `f'<0`，当 `x>x_0` 时 `f'>0`，所以在 `x_0` 处有唯一极小值。
这个推导不包含任何未提供的第三小问。
