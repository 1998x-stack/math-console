# Manim 数学动画工程约定

## 版本与可移植性
目标 Manim Community 0.19.x，生成代码写明版本约束，避免使用 ManimGL 专属 API。不要把 MathTex/LaTeX 字体与 Text 中文字体混淆。Docker 镜像安装 Noto CJK，可在不同 Linux 主机重现；不能保证所有字体风格跨平台一致。

## 代码设计
一个 `LessonScene(Scene)` 入口，场景内部提取 `build_header`、`draw_graph`、`show_derivative` 等可修改方法。用 `self.play` 显式呈现逻辑步骤，`self.wait` 留出学生思考；不要把全部逻辑写成几百行匿名 lambda。

图像优先使用 `Axes.plot`、`Dot`、`Line`、`VGroup`、`MathTex` 与 `Text`。计算坐标时设置可见域与避免奇点。在 x>0 的对数图像中不能从 x=0 直接取对数，x_range 起点应是正数。

## 质量守则
- 每场景包含 `# beat_id: ..., step_ids: ...` 以便分镜追踪。
- 文本与图像不得覆盖，数学符号避免过小。
- 颜色同时辅以标签，适配不同背景。
- 代数变形保持项的对应关系，避免把没有逻辑等价的两个式子直接 `TransformMatchingTex`。
- 不允许生成“证明”却只播放画面，证明步骤必须出现。
- 渲染后用真实帧检查溢出、闪烁、时序、中文缺字。

## 安全
Python 动画脚本是可执行程序。静态黑名单只能发现部分明显风险，恶意代码可绕过；必须有独立资源隔离、只读输入、无网络、低权限、CPU/RAM/PID/时间限制、禁止挂载宿主敏感目录。MCP 服务端不得把 Agent 生成的代码直接写入宿主解释器。

## 可维护性
源码作为正式交付，视频只是衍生物；保存版本、质量等级、镜头分镜、所有依赖声明。不要依赖随机动画结果，每次渲染应可复现。
