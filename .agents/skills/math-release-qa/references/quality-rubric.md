# 教学包发布质检评分与阻塞标准

## P0 致命阻塞（任何一项失败必须停止）
- 原题符号/图形关系存在未解决歧义。
- 任一小问未完成，或者关键证明缺失、与给定条件矛盾。
- audit 不是独立审校，或者高风险证明缺教师人工签核。
- storyboard 中有未经审核的新结论，Manim 代码无法真实渲染。
- 缺少 MP4、音轨、可编辑源码或 PPTX；没有真实证据却写“已完成”。
- 教学内容含未经许可的敏感学生数据、未经授权传播的版权材料。

## P1 重要质量问题（回退对应阶段）
- 视频字幕/公式遮挡、图像跨页溢出、动画节奏与旁白不匹配。
- 把“切线似乎水平”当作极值的证明，把抽样当不等式证明。
- PPT 题目过密、答案提前出现在学生页、公式难以辨认。

## P2 体验优化
- 动画风格不统一、教学追问点不足、练习难度梯度不顺畅。
- 生成成本/渲染时间可进一步优化。

## 一致性追溯
题号对应 question_id，解题步骤对应 step_id，分镜引用 step_id，练习引用 target_step_ids；每份文件结构和哈希归档。视频质量还需教师抽样观看，ffprobe 只能证明容器格式与真实轨道存在，不能证明“讲得好”。

## 完整交付
run.json, 原图, problem.json, solution.json, solution.md, audit.json, storyboard.json, storyboard.md, lesson_scene.py, silent.mp4（可选预览）, lesson.mp4（带真实音轨）, practice.json, practice.pptx, release.json。

脚本可重算 SHA 检测发布后被改动；但报告文件被恶意篡改时无数字签名保证，生产环境应结合 CI 记录与对象存储不可变版本。
