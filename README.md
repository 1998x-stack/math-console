# Math Console

AI 数学教育产品规划与原型资料。

本仓库收录三个相互协同的产品方向：

- **A / AI 数学教师工作台**：经过数学审校的题目讲解、分镜、可编辑 Manim 动画和课堂资源。
- **B / AI 数学交互实验室**：以参数拖动、图形探索、预测与验证为核心的交互式数学课堂。
- **C / AI 个性化数学导师**：分层提示、错因识别、知识诊断和学习效果评估。

PDF 文档将放在 `docs/product-plans/`，源文件与再生成流程放在 `scripts/`。

> 文档中有关预算、定价、实施周期和增长目标的数字是规划假设，并非经过验证的商业事实。
